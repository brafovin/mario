# The Little Child

Ein kleines Browser-Spiel, in dem du Elternteil eines 8-jährigen Mädchens bist.

## Die Hauptfigur
**Mia**, 8 Jahre alt, besucht die 3. Klasse.
- Lange schwarze Haare
- Blaue Augen
- Dünn, helle Haut

## Spielidee
Du bist ihre Mama oder ihr Papa und musst dich eine Woche lang (7 Tage) um Mia
kümmern. Halte ihre Bedürfnisse in Balance und schau, wie gut du als Elternteil bist.

## Aktionen
- 🎒 **Zur Schule bringen** – jeden Morgen (7:00–9:00 Uhr)
- 💼 **Zur Arbeit gehen** – um Geld zu verdienen
- 🍳 **Essen machen** – Butterbrot, Nudeln oder gesundes Essen
- 🛒 **Einkaufen** – Lebensmittel für den Kühlschrank
- 👗 **Kleidung kaufen** – Kleid, Jacke oder Schuhe
- 🧸 **Spielen** – basteln, Park, vorlesen
- 🛁 **Baden** – für saubere Mia
- 🌙 **Schlafen** – regeneriert Energie

## Statuswerte
- 😊 Glück
- 🍎 Hunger
- ⚡ Energie
- 🧼 Sauberkeit
- 📚 Schule
- 💶 Geld

## Starten
Öffne einfach `index.html` im Browser – fertig!

```bash
# Optional: lokaler Server
python3 -m http.server 8000
# dann http://localhost:8000 öffnen
```

Keine Abhängigkeiten, kein Build-Schritt.
